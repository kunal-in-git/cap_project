Issue: mcp_server.py opened the database with a relative path (DB_PATH = "library.db"). SQLite resolves relative paths against the process's current working directory, not the script's location. Since the MCP server process was running with cwd = project root (cap_assisment/), it connected to (and silently auto-created) an empty library.db there instead of the real, seeded one in phase3/task2/ — hence "no such table: books".

Fix:
1. Changed DB_PATH in mcp_server.py to resolve relative to the script's own location: Path(__file__).resolve().parent / "library.db".
2. Deleted the stray empty library.db that had been auto-created at the project root.

Restarting the MCP server is required for the fix to take effect.
