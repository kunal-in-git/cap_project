# cap_project

Capstone assignment work, organized by phase.

## Phase 1

- [Task 1 — FastAPI + React Mini Project](phase1/task1/README.md): a Task Management app with a FastAPI backend and React frontend.
- [Task 2 — PostgreSQL Query Set](phase1/task2/README.md): schema, sample data, and 5 required queries against an employees/projects database.
- [Task 3 — Neo4j Cypher Query Set](phase1/task3/README.md): a social network graph and the required Cypher queries.
- [Task 4 — AI-Gated SDLC Flow Document](phase1/task4/README.md): the full SDLC (requirements → design → coding → testing → deployment) for one Task Manager feature, documented with real AI prompts and outputs at each stage.

## Phase 2

- [Task 1 — Claude Code CLI: Autonomous Python Utility Module](phase2/task1/README.md): a CSV data cleaner generated, refactored, and tested autonomously by Claude Code CLI.
- [Task 2 — Agentic GitHub Contributors Pipeline](phase2/task2/README.md): a text-file-in → GitHub API → markdown-report-out pipeline with real error handling and logging.
- [Task 3 — Mini-Tasks: Copilot vs. Claude](phase2/task3/README.md): three small prompts (email regex, SQL duplicate query, JS Promise explainer) answered by both tools for comparison.

## Phase 3

- [Task 1 — FastAPI + LangChain LLM Service](phase3/task1/README.md): an LLM-powered `/ask` endpoint with LangChain, per-session conversation memory, and a Dockerfile.
- [Task 2 — MCP Server over a Local SQLite Library](phase3/task2/README.md): an MCP server exposing a search tool and a stats tool, connected to and demonstrated with Claude.
- [Task 3 — Figma-to-React: Pricing Card](phase3/task3/README.md): a React pricing card component built from a design brief, reviewed and fixed against real AI-generated shortcomings.
